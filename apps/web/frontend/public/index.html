Is this repo safe to open?

Got a take-home coding test from a recruiter? Paste the link or upload the ZIP. We check it for hidden traps that run code the moment you open or install it, without running any of it.

or upload a ZIP (up to 50 MB)

What we look for

  • VS Code tasks that run when you open the folder, and settings that start programs from the repo
  • npm, Python and dev container scripts that run on install or setup
  • Git hooks and git config hidden in ZIP downloads
  • Hidden or obfuscated code, and code that downloads more code and runs it
  • Look-alike package names and dependencies pulled from random URLs

A scan lowers your risk but can't prove a repo is safe. Public GitHub, GitLab and Bitbucket repos only. Uploaded ZIPs are deleted right after scanning; reports are kept for 30 days so you can share them.
